Fault history, with what the system concluded

One row per injected fault, including the ones nothing detected — a history that listed only detected faults would be the most misleading view here. No remedy in this system is ever carried out: the executor records intent and is architecturally unable to act, so a service recovers when the injector withdraws the fault, never because an action fixed it.
